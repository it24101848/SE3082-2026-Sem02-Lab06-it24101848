CODE ============================================================

#include <omp.h> #include <stdio.h>

int main() { #pragma omp parallel { int th = omp_get_thread_num();

        printf("thread # %d\n", th);

        #pragma omp barrier

        printf("Outside Barrier # %d\n", omp_get_thread_num());
        printf("Hi again from thread # %d\n", omp_get_thread_num());
    }

    return 0;

}

============================================================ 5.
DESCRIPTION OF #pragma omp barrier
============================================================

#pragma omp barrier creates a synchronization point inside an OpenMP
parallel region. When a thread reaches the barrier, it must wait until
all other threads in the team have also reached the same barrier. Only
after every thread reaches the barrier can the threads continue
executing the statements after it.

In this exercise, each thread first prints its thread number. The
barrier then makes the threads wait for one another. Therefore, all
“thread #” messages are produced before execution continues to the
“Outside Barrier” section.

The order in which individual threads execute is not guaranteed. This
can be seen in the output because the thread numbers do not necessarily
appear in numerical order.
