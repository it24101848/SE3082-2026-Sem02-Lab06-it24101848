============================================================ 1. SOURCE
CODE ============================================================

#include <omp.h> #include <stdio.h>

int main() {

#pragma omp parallel { int th = omp_get_thread_num(); printf(“thread #
%d”, th);

#pragma omp single { printf(“Inside Single # %d”, omp_get_thread_num());
printf(“Exiting Single ”); } printf(“Hi again from thread # %d”,
omp_get_thread_num());

} return 0; }

============================================================ 5.
DESCRIPTION OF #pragma omp single
============================================================

#pragma omp single specifies that the structured block associated with
the directive is executed by only one thread in the current team.

The thread that executes the single region is not required to be thread
0. In the actual results of this exercise, thread 1 executed the single
region in both the 2-thread and 4-thread runs.

The other threads do not execute the statements inside the single block.
Unless the nowait clause is used, an implicit barrier exists at the end
of the single construct, so threads wait there before continuing beyond
the construct.

In the output, “Inside Single # 1” and “Exiting Single” appear only once
in each execution, demonstrating that only one thread executes the
single block.
